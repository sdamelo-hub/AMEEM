# 🎓 AMEEM — Amicale des Étudiants Mbourois

## 🚀 Déploiement Vercel (3 étapes)

### Option A — GitHub + Vercel (Recommandée)
1. Créer un repo GitHub et pousser ce dossier
2. Aller sur vercel.com → New Project → Importer le repo
3. Cliquer Deploy ✅ (Vite est auto-détecté)

### Option B — CLI
```bash
npm install -g vercel
vercel login
vercel --prod
```
